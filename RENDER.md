# Render deployment

The repository includes `render.yaml` for two Render services:

- `farmproduce-api`: FastAPI API service.
- `farmproduce-frontend`: Vite static site.

## Deploy with the Blueprint

1. Push the repository to GitHub.
2. In Render, choose **New > Blueprint** and select the repository.
3. Before the first deploy, set `DATABASE_URL` on `farmproduce-api` to a hosted PostgreSQL connection string.
4. Set `VITE_API_BASE_URL` on `farmproduce-frontend` to the API service URL, for example `https://farmproduce-api.onrender.com`.
5. After the frontend deploys, set `FRONTEND_URL` on `farmproduce-api` to the frontend URL, for example `https://farmproduce-frontend.onrender.com`.
6. Redeploy the API after setting `FRONTEND_URL`.

`FARMMARKET_TOKEN_SECRET` is generated by Render. SQLite is only a local fallback;
production data must use PostgreSQL because Render service filesystems are not a
durable database.
